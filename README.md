# Project LOOP - Enterprise Multi-Tenant Feedback Analytics Platform

Project LOOP is a modern, corporate-grade **Full-Stack Feedback Intake & Retrieval-Augmented Generation (RAG) Platform** built for the Zidio Technology Internship. It provides real-time multi-tenant data isolation, role-based access controls, and an advanced automated text analysis engine.

## 📁 System Architecture & Directory Tree

- **`/backend`**: Express.js server engine connected to a Neon PostgreSQL cloud cluster via Sequelize ORM.
- **`/frontend`**: Optimized Vite + React workspace stylized with a premium, glassmorphic dark theme and a hardware-accelerated 3D Vanta Net background mesh.
