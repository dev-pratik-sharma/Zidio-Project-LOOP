# 📊 Project LOOP - Glassmorphic Workspace Dashboard

This directory houses the interactive client application workspace built to map aggregated system metrics, handle live single and batch data uploads, and talk securely to your analytics endpoints [INDEX_0.1.3, INDEX_0.1.11].

## 🎨 Creative Engineering Stack
- **Framework Driver:** Vite + React.js
- **Styling Utility Engine:** Tailwind CSS v4 Framework
- **WebGL Background Node:** Hardware-Accelerated 3D Vanta Net Mesh

## 🚀 Local Initialization Sequence
To turn on this visual client view port, install your local packages and boot the hot-reloading dev compiler:

```bash
npm install
npm run dev
```
